Sobre los datos

API utilizada

Este proyecto utiliza la Dragon Ball API, una API pública que proporciona información sobre personajes, transformaciones y otros elementos del universo Dragon Ball.

Mantenimiento

La API es mantenida por sus desarrolladores y está disponible públicamente para proyectos educativos y de aprendizaje.

Licencia y atribución

Los datos pertenecen a sus respectivos autores y propietarios de Dragon Ball. Este proyecto utiliza la información únicamente con fines educativos, indicando que los datos proceden de la Dragon Ball API.

Peticiones realizadas

  • GET https://dragonball-api.com/api/characters

Transformación del JSON a HTML

Fragmento del JSON recibido:

{
    "id": 1,
    "name": "Goku",
    "race": "Saiyan",
    "gender": "Male",
    "affiliation": "Z Fighter"
}

Resultado en HTML:

<article>
    <h3>Goku</h3>
    <p>Raza: Saiyan</p>
    <p>Género: Male</p>
    <p>Afiliación: Z Fighter</p>
</article>
